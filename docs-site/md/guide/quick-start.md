# 快速上手

从安装到完成第一条 AI 对话。

## 系统要求

- Android 8.0（API 26）及以上
- arm64-v8a 或 x86_64 设备

## 下载安装

**官网优先**：[官网下载页](https://aivapp.cn/download)（推荐）提供最新稳定版与历史版本；也可从 [GitHub Releases](https://github.com/yhdmgf/AiVerse/releases/latest) 下载。三个包按设备选择：

| 包名 | 适用场景 |
| --- | --- |
| `armsolo` | 真机（arm64 设备），体积最小 |
| `x86solo` | 模拟器、Chromebook（x86_64） |
| `universal` | 通用包，同时含两种架构，体积较大 |

::: warning 架构要选对
架构不匹配会导致内置容器无法运行。不确定时使用 `universal`。
:::

## 选择版本

AiVerse 同时提供三个版本，用途不同，请按需要选择：

| 版本 | 适合谁 | 版本号形态 | 说明 |
| --- | --- | --- | --- |
| **正式版** | 想要稳定 | 干净的版本号，如 `1.0.3` | 经过验证的稳定版本，日常维护与迭代都基于它 |
| **预览版** | 想提前体验新功能、但仍要相对可用 | 正式版加 `rc` 后缀，如 `1.0.3-rc3` | 正式版的候选版本，比测试版稳定，适合尝新功能 |
| **测试版（Beta）** | 仅供测试，**不推荐使用** | 独立编号，比正式版多一个版本并带测试版号 | 带水印、不参与应用内检查更新，不适合长期使用 |

- **想要稳定，就用正式版**：见上方[官网下载页](https://aivapp.cn/download)。
- **想要测试新功能，就用预览版**：见 [GitHub Releases](https://github.com/yhdmgf/AiVerse/releases) 中带 `rc` 的构建。
- **测试版不推荐使用**：它每日定时构建服务器上的最新代码，用于验证最新版能否正常工作。但测试版版本号与正式版、预览版都不相同，不能正常维护和迭代，可能不稳定甚至存在高危问题；App 各页面还会显示 **Beta** 水印，且不参与应用内检查更新。

::: tip 测试版从哪来
测试版发布到 [aiverse-beta Releases](https://github.com/yhdmgf/aiverse-beta/releases)。该 commit 尚未定时构建时，可到[测试版触发页](https://aivapp.cn/trigger/)一键代触发 `Nightly Build`（全局限频，1 小时一次），或等下一个定时点（北京时间 0/6/12/18 点）。
:::

## 1. 配置 AI 供应商

::: tip 首次启动有新手引导
首次启动时会自动开启新手引导（1.0.0 新增），依次引导完成下面几步；也可随时点击「跳过」，或之后在「设置 → 重新运行新手引导」再次启动。
:::

AiVerse 自身不提供模型，需要先接入一个模型服务。

1. 点主页左上角菜单按钮打开侧边栏，点底部「设置」。
2. 进入「AI 配置 → AI 供应商」，点右上角 + 新建，在「配置」标签填写四项：
   - **名称**：别名，例如「官方 OpenAI」。
   - **上游格式**：`OpenAI` / `Anthropic` / `Gemini` 三选一。第三方中转站一般选 `OpenAI`。
   - **API Key**：你的密钥，形如 `sk-xxx`。
   - **Base URL**：API 根地址，**留空时按上游格式使用官方地址**；用第三方中转时填入中转服务的地址。
3. 底部切到「模型」标签添加模型：
   - 点击「拉取模型」从服务端同步可用列表，点击每行右侧的「+」逐个添加，或用右上角「全部添加」一键加入。
   - 点击右上角 + 手动输入模型名（例如 `gpt-4o`）。中转站模型名拉取不全时使用此方式。
   - 可选：点击模型行编辑元数据（上下文窗口、价格、图片输入与工具调用等能力开关）。

填完退出编辑页时会自动保存，没有单独的保存按钮。

## 2. 选择模型

回到聊天主页，点击输入框下方工具栏的模型按钮，在弹窗中选择刚添加的模型。顶部搜索框可以筛选，模型按供应商分组显示，点击分组标题可以折叠或展开。

## 3. 准备执行环境

默认使用内置的本地容器，无需任何配置。第一次使用时，在主页点击进入终端，按提示完成一次初始化即可（解压系统、安装基础工具），之后 AI 就能正常执行命令。

如需把远程服务器当执行后端，见[远程 SSH 模式](https://aivapp.cn/md/guide/remote-ssh.md)；容器与镜像的详细设置见[容器与镜像](https://aivapp.cn/md/guide/container.md)。

## 4. 开始对话

在输入框输入内容后点击发送。输入框下方工具栏最左侧的模式按钮可以在 BUILD、PLAN、AUTO 之间切换，区别见[四种模式](https://aivapp.cn/md/guide/modes.md)。

## 实用贴士

- 在主页空会话中选择的模型将被记录为新会话的默认模型，后续新建会话自动沿用。
- 识图、生图与标题总结支持独立指定专属模型，详见[默认模型](https://aivapp.cn/md/guide/default-models.md)。
- AI 修改代码前会自动创建快照，支持一键安全回滚，详见[检查点与撤销](https://aivapp.cn/md/guide/checkpoint.md)。
- 执行编译等耗时任务前，建议开启[软件权限](https://aivapp.cn/md/guide/app-permissions.md)中的后台运行保活，防止系统在切换后台时终止进程。
