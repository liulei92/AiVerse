# 从正式版导入数据

AiVerse 的测试版（beta）和正式版是同一签名下的两个独立应用，各自保存自己的数据：模型配置、技能、聊天记录等互不同步。装了测试版之后，不需要把配置重新做一遍，可以把你正式版里已经在用的配置直接搬过来。

## 会导入哪些数据

- 技能
- MCP 服务器配置
- 角色（AI 人设）
- 工具授权规则
- 应用设置（主题、外观、语言、偏好等）
- 模型供应商与模型列表
- Git 凭据

::: tip 导入是合并，不是清空
导入不会删除测试版已有的数据。同名条目会用正式版里的内容覆盖测试版的对应条目，其余条目保持原样。
:::

## 不会迁移的内容

容器里的运行环境（Node.js、Python、Git 等基础工具）不随数据一起迁移，测试版会按自己的流程重新初始化容器。第一次打开终端时仍要等容器准备完成；装在容器里的第三方工具（Flutter SDK、Playwright 浏览器等）也需要重新安装。

::: warning 聊天记录不在导入范围
这次导入只搬配置类数据，不包括聊天会话与消息、工作区文件。想要跨版本保留聊天记录，请用[备份与还原](https://aivapp.cn/md/guide/backup.md)。
:::

::: warning 测试版不推荐作为日常主力版本
测试版按天构建、界面带水印，不保证稳定，也不参与应用内更新检查。正式工作仍建议使用正式版或预览版（见[快速上手](https://aivapp.cn/md/guide/quick-start.md)的版本选择说明）。
:::

## 操作步骤

1. **测试版首次启动**：同意用户协议后，首页会出现「从正式版导入数据」引导卡。
2. **点「导入」**：系统会自动打开正式版 AiVerse。手机上没装正式版时会提示找不到正式版，请先安装正式版再重试。
3. **在正式版里确认授权**：正式版会弹出一个授权页面，说明这次送出的数据范围与风险，并逐项列出数据清单。
4. **点「允许」**：数据自动传到测试版并导入。完成后正式版提示授权已结束，测试版也会给出导入完成的提示。
5. **临时文件自动清理**：正式版在导入结束后会自动删除本次产生的临时文件，不需要你手动处理。

这次不想导入也没关系，可以点「稍后」或关闭引导卡，测试版仍能正常安装使用；下一次启动时会再次出现引导卡。

## 通道怎么选

授权页面会让你选择这次传输走哪条通道。两条通道都能完成导入，差别在稳定性：

| 通道 | 特点 | 什么时候用 |
| --- | --- | --- |
| **推荐通道**（默认选中） | 数据全程留在正式版内部，只给本次导入临时一次读取授权，读完立刻收回，其他应用碰不到这些数据 | 绝大多数情况直接用这条 |
| **备用通道** | 正式版在你手机内部起一个只在本机生效的临时连接，读完数据后自动关闭 | 推荐通道读取失败时改这条再试 |

::: tip 不需要额外权限
两条通道都不需要开放存储权限，也不需要联网，整个过程都在你自己的手机上完成。
:::

## 常见问题

**点「导入」后没反应，或提示找不到正式版**

确认正式版已安装并且能正常打开；测试版和正式版必须装在同一台手机上。

**正式版里没弹出授权页面**

授权请求可能被系统拦下，或者正式版被切到了后台。把正式版切回前台，授权页面会重新出现；如果一直没有，回到测试版引导卡重新点一次「导入」。

**授权页的数据清单看着不对**

授权页列出的就是你点「允许」之后会送出的内容，请逐项核对，确认无误再允许。

**导入到一半失败了**

测试版会给出失败提示。可以从引导卡重新点「导入」再试一次，或换另一条通道重试。

**导入完了还是缺东西**

先对照上文「会导入哪些数据」和「不会迁移的内容」：聊天记录、工作区文件、容器里装好的运行环境都不在这次导入范围内。
